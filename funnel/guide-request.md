# Запрос гайда вместо «Купить»

Оплаты нет. Кнопка «Купить» и «Оплата скоро» не ставятся. Человек жмёт «Получить гайд», бот пишет Alex, Alex нажимает «Отправить», бот присылает PDF в тот же чат.

Бот не может написать первым. Кнопка на Тильде — ссылка `https://t.me/<bot>?start=<код>`. Человек открывает бота и жмёт «Старт».

Коды, пока других принятых гайдов нет:

- `free11` — «11 запросов», бесплатно. Отдать сразу, без аппрува. Файл `products/free-11-zaprosov/AI-Prosto-11-zaprosov.pdf`.
- `bumazhki` — «Нейросеть для бумажек», 390 ₽. Только после «Отправить». Файл не класть в `pub/`.

Карточки на Тильде без своего PDF («документы», «договор», «жалоба», «быт», набор) кнопку запроса не получают: отправлять нечего.

Сообщение Alex: имя, @username, id, код гайда, время. Кнопки: «Отправить» и «Не сейчас». «Не сейчас» — короткая отписка, без файла. Повторный «Старт» с тем же кодом не шлёт второй PDF, пока Alex снова не подтвердит платный.
