<b>Claude переписал свой API на Rust</b>

25 ноября Anthropic описала перенос Messages API с Python на Rust. Через этот API ходят клиенты и их же приложения — Claude Code и Cowork. Сервис не останавливали.

По их замерам: на один запрос уходит примерно на 70% меньше процессора, медиана времени до первого слова ответа ниже примерно на 20%.

Обычному человеку ничего ставить не нужно: изменение на стороне Claude. Если первое слово ответа появляется чуть раньше — это как раз тот замер. Цифра про API, не обещание для каждого чата.
