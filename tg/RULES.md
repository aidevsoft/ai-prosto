# Правила канала @about_ai_easy

Пост = файл `tg/queue/YYYY-MM-DD-HHMM-<id>.md`. Время — Тбилиси (+04). Публикует cron на Almaty каждые 10 мин (`/usr/local/bin/ai-prosto-tg.sh`). GitHub Actions не включать параллельно. Опоздание больше `expires_h` (по умолчанию 12 ч) — пост пропускается. Состояние — `CONTEXT.md`, раздел «Telegram».

```
---
at: "2026-11-27 20:05"
kind: pair | news | hack | evergreen | pinned
reel: reel21          # для pair
photo: tg/img/x.jpg   # необязательно; подпись ≤ 1024 символа
preview: true         # превью ссылки, по умолчанию выключено
pin: true             # закрепить
expires_h: 72
---
Тело в Telegram HTML: <b> <i> <u> <s> <a href> <code> <pre> <blockquote>.
```

## Направление с 7.12.2026

Читатель ничего не знает про ИИ. Пост ведёт его по тому же плану, что рилс (`QUALITY.md`, «Направление»): какие бывают, как ими пользоваться, что бесплатно и что платное, чем отличаются, что открывается в РФ, российские сервисы, недоступный — «включи VPN и открой сайт». Без схем обхода и без оплаты.

13:05 — пара к мысли дня. 20:05 — пара к одному действию в чате, который в этот день открывается. Запрос в паре — целиком из ролика, не свой. «11 запросов» и «бумажки» — следующий шаг, когда чат уже открыт.

## Сетка

- 09:30 — новость ИИ: официальный источник не старше 48 ч, одна мысль + что с ней делать обычному человеку. Новостей нет — пропускаем, не выдумываем.
- Слот рилса + 5 мин — пара к рилсу: полный запрос в `<pre>` + 2–3 детали, которых не было в ролике.
- Каждые 2–3 дня — лайфхак или вечнозелёный пост.
- В каждом 3-м посте одна ссылка на лендинг `https://ai-code-review.tilda.ws/` с UTM `utm_source=telegram&utm_medium=post&utm_campaign=about_ai_easy&utm_content=<id>`. GitHub Pages не ставить. Больше одной продающей ссылки в посте не бывает.

## Нельзя

- Обещать доход, гарантии, «100 %», юридические и медицинские выводы.
- «Купить» / предзаказ / сбор денег, пока оплата выключена.
- Ссылки не https, свои ссылки без UTM.
- Писать то, чего нет в источнике (для новостей — только официальный источник).

Проверка: `tools\tg\check.py` в GrokMigration. Не вышло — смотри `/var/log/ai-prosto-tg.log` на Almaty.
