# Правила канала @about_ai_easy

Пост = файл `tg/queue/YYYY-MM-DD-HHMM-<id>.md`. Время — Тбилиси (+04). Публикует GitHub Actions каждые 10 мин. Опоздание больше `expires_h` (по умолчанию 12 ч) — пост пропускается.

```
---
at: "2026-11-27 20:05"
kind: pair | news | hack | evergreen | pinned
reel: reel21          # для pair
photo: tg/img/x.jpg   # необязательно; подпись ≤ 1024 символа
preview: true         # превью ссылки, по умолчанию выключено
pin: true             # закрепить
expires_h: 72
---
Тело в Telegram HTML: <b> <i> <u> <s> <a href> <code> <pre> <blockquote>.
```

## Сетка

- 09:30 — новость ИИ: официальный источник не старше 48 ч, одна мысль + что с ней делать обычному человеку. Новостей нет — пропускаем, не выдумываем.
- Слот рилса + 5 мин — пара к рилсу: полный запрос в `<pre>` + 2–3 детали, которых не было в ролике.
- Каждые 2–3 дня — лайфхак или вечнозелёный пост.
- В каждом 3-м посте одна ссылка на сайт с UTM `utm_source=telegram&utm_medium=post&utm_campaign=about_ai_easy&utm_content=<id>`. Больше одной продающей ссылки в посте не бывает.

## Нельзя

- Обещать доход, гарантии, «100 %», юридические и медицинские выводы.
- «Купить» / предзаказ / сбор денег, пока оплата выключена.
- Ссылки не https, свои ссылки без UTM.
- Писать то, чего нет в источнике (для новостей — только официальный источник).

Проверка: `tools\tg\check.py` в GrokMigration. Ничего не опубликовано — смотри вкладку Actions репозитория.
